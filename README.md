An interactive, tactical HUD developer portfolio inspired by the **Batcomputer OS** from *The Batman (2022)*. Engineered with pure HTML5, CSS3, and Vanilla JavaScript—zero external UI frameworks—featuring real-time API telemetry, an interactive command-line interface (CLI), in-page system architecture blueprints, and a custom Web Audio API synthesizer.

---

## ⚡ Key Engineering Highlights

* **Interactive Batcomputer CLI Drawer (`Press ~`):** A built-in command-line terminal supporting live queries (`help`, `about`, `skills`, `projects`, `clearances`, `leetcode`, `theme amber|crimson|emerald`, `contact`, `clear`).
* **Real-Time API Telemetry:** Dynamically fetches public repository metrics from the **GitHub REST API** (`api.github.com/users/dhruvpathak23`) and renders a live **LeetCode DSA Heatmap & Stats Card** (`@dhruvhacks`).
* **System Architecture Blueprints:** Interactive modal popups on project cards illustrating end-to-end data pipelines (NLP tokenization, FinBERT sentiment triggers, Whisper STT, and React REST architectures).
* **In-Page Combat Simulator Launcher:** Embedded iframe modal system allowing visitors to play the **Minimax Tic-Tac-Toe** and **Markov Chain Stone-Paper-Scissors** simulators directly inside the portfolio without leaving the page.
* **3-Mode Tactical HUD Theme Engine:** Instant CSS Custom Property switching between **Vengeance Crimson (`#ff0a16`)**, **Knightfall Amber (`#ff9900`)**, and **Nightvision Emerald (`#00ff88`)**.
* **Zero-Asset Web Audio Synthesizer:** Generates tactical UI clicks, terminal chirps, and confirmation tones dynamically via the browser's `AudioContext` oscillator nodes.
* **HTML5 Canvas Gotham Rain & 3D Tilt Physics:** Custom 60FPS particle rain animation paired with mouse-tracked 3D perspective card tilting and printable PDF dossier (`@media print`) support.
